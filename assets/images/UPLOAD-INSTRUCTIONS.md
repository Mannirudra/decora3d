# Decora3D — Product Image Upload Instructions

This folder contains **36 branded SVG placeholder images** — one per product.
They display the product name, category, price, and material in Decora3D's
dark gold brand style.

## How to Upload to Shopify (2 minutes)

### Option A — Bulk Upload via Shopify Files (Recommended)
1. Shopify Admin → **Settings → Files**
2. Click **Upload files**
3. Select ALL 36 `.svg` files from this folder (Ctrl+A / Cmd+A to select all)
4. Click Upload
5. Once uploaded, click each file → **Copy link**
6. Fill those links into `image_cdn_urls.json` (auto-generated by the helper script)
7. Run: `python3 update-image-urls.py` to update the CSV

### Option B — Shopify CLI (fastest, one command)
If you have Shopify CLI installed:
```bash
shopify theme push --store=decora3d.myshopify.com --only assets/images/
```
Then images are at:
`https://cdn.shopify.com/s/files/1/XXXX/XXXX/files/placeholder-HANDLE.svg`

### Option C — Upload during Product Import (manual)
Skip the CDN step. After importing the CSV (with REPLACE_WITH_CDN in image column),
go to each product and upload its image manually. The SVGs are in this folder.

---

## Replace with Real Photos Later
When you have real product photos:
1. Go to Products → [product name] → Add media
2. Upload your real photo
3. Drag it to Position 1 (first image shown)
4. Delete the placeholder SVG

The placeholders are designed to look professional enough for a launch day.
Real photos should be added within the first 2 weeks.

---

## File Naming Convention
All files follow: `placeholder-{product-handle}.svg`

Example: `placeholder-voronoi-pendant-lamp.svg`
→ matches product handle: `voronoi-pendant-lamp`
